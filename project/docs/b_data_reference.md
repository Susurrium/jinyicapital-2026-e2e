# 数据与输入合同

数据适配沿用 `ptop.raw25.v1`。输入包含 OHLC、成交量、成交金额、成交笔数，以及前三档买卖报价、挂单量和委托笔数，字段顺序由 `ptop.schema.FEATURES` 固定。`adjust_factor` 作为来源元数据保存。

本地价格和金额按来源定义换算为元，云端保持其元单位。OHLC 缺失值与盘口价格哨兵分别识别；真实零数量与缺失值通过独立 observed 区分。未知负值依显式读取策略处理。

模型接收 `float32[B,L,25]`、`bool observed[B,L,25]` 和 `bool step_valid[B,L]`。窗口按显式分钟网格构造，默认不跨日；真实分钟缺行仍保留时间槽，左侧历史不足使用结构填充。

正式数据接入需提供官方应预测集合、真实股票映射、分钟网格、可见性、LabelSpec 及目标支持区间。行情数据不能替代这些合同。原始数据和样例由各自授权环境提供。
