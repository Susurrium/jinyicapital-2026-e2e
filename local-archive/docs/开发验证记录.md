## 验证范围

环境：Windows x64，Python 3.12.10、PyTorch 2.8.0 CPU、pandas 2.2.3、NumPy 2.2.6、Arrow 20.0.0。组件边界与等价测试使用合成数据及真实库；本地归档验收和七日 N0/N1 数值检查已使用真实 1 分钟数据，尚未进行监督训练。

当前全量代码验证：**199 passed in 48.02s**，进程退出码 0。逐项结果见 [测试记录](../reports/local-data/test-results.xml)，独立合成流程结果见 [运行摘要](../reports/synthetic-validation.json)。真实数据验收结果见[本地 1 分钟检查](本地1分钟数据验收与预处理检查.md)：全包 302,545,707 行中存在 8,084 个未知负委托笔数，源数据合同验收未通过。

- 与同权重锁定 Qlib 模型比较前向、输入梯度与全部参数梯度；float32 容差 `atol=1e-6, rtol=1e-5`。
- 与官方 N0/N1 处理器比较整体、逐列、分区、重载结果；N2 使用官方单列 pooled-price 拟合，验证价格顺序与仿射还原。
- 检查单位与哨兵、重复键、缺失字段、真实零、可见性、跨日边界、全市场缺失分钟、分区与样本顺序。
- 真实 PyTorch DataLoader 在单进程及 Windows spawn 单 worker 下保持数值、mask、元数据和源行索引一致；每批为完整决策截面，保留尾截面并验证独立随机状态。
- 检查 packing、注意力、BN、patch 展平、DeepLOB 空间宽度与 padding、负值池化边界、LSTM 权重门序与初始化。
- 对全部九种模型检查联合梯度与状态；JSON 包验证字段、配置、形状、类型、BN buffers、文件哈希和加载行为。
- 标签检查采用显式支持区间；NaN 缺失保持无效，非法无穷值阻断操作。输出使用完整应预测集合验证逐时点缺失率。
- DAI 查询只完成注入式接口与隔离 QuerySpy 路由测试，未连接真实 DAI 服务。DeepLOB 未运行 TensorFlow 跨框架测试。

## 交接

A 向 B 提供 float32 `[B,L,25]`、bool observed 和 step_valid，以及编码器 `(tokens,token_valid)`。实际使用字段决定 predictable，纯空窗口必须在模型调用前分流。R1 默认 token 宽度 64，R0 为 50，分组与 DeepLOB 为 192。

A 向 C 提供完整 expected、稳定 sample_id／decision_id、显式标签支持区间及逐时点覆盖审计。`official_targets` 需要已确认支持表；不能从目标列名推断结束时刻。模板中的训练日期和样本删减行为不决定正式覆盖分母。
