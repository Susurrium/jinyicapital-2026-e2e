# A 模块开发与验证

A 模块实现了 raw25 数据规范化、观测掩码、当日窗口、训练引用原始行并集、冻结 N0/N1/N2、九种参照模型、标签支持区间与输出覆盖检查，以及 v2 JSON 模型包。

Qlib 组件来自固定提交 `54355232463878d2eebb91fe0ee5fa7fa1f5976c`，以源码保存在 `src/ptop/_vendor/qlib/`，常规运行无需外部 `pyqlib`。

公开保存的历史记录位于 [reports/](../reports/)：早期代码测试 154 项通过，无外部 Qlib 的独立环境测试 218 项通过。合成验证包含联合梯度、实际激活、逐时点覆盖及独立进程恢复；这些结果不表示金融收益预测效果。

完整训练、断点恢复和参数化模型包已集成到 [project/](../../project/README.md)。正式使用需要实际授权日期、官方采样与股票映射、分钟网格、可见性、标签定义及支持区间。完整历史记录和真实数据审计明细见 [原始资料快照](../../local-archive/)。
